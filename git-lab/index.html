Репозиторий ещё не создан

Начните с git init: эта команда создаст каталог .git для хранения истории и настроек репозитория.

$git init

Это визуальная модель, не настоящий терминал и не выполнение команд на вашем компьютере.

04 / ПРОЕКТИРОВАНИЕ СИСТЕМ

Настоящий frontend + backend

Этот учебник одновременно иллюстрирует клиент-серверную архитектуру. Интерфейс доступен на GitHub Pages; API для сохранения прогресса работает на FastAPI, используя SQLite.

Локальный режим: данные сохраняются в браузере.

Для сайта на HTTPS сервер тоже должен использовать HTTPS. Без API тренажёр и справочник продолжат работать.
