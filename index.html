О проекте

Этот сайт создан для демонстрации современных инструментов веб-разработки и системы контроля версий Git.

Проект позволяет изучить основные этапы разработки веб-сайта: создание HTML-страницы, изменение исходного кода, сохранение истории изменений и публикацию в интернете.

Инструменты веб-разработчика

Для разработки и публикации проекта используются следующие технологии:

  1. HTML — язык разметки, определяющий структуру веб-страницы.
  2. Visual Studio Code — редактор исходного кода.
  3. Git — распределённая система контроля версий.
  4. GitHub — платформа для размещения Git-репозиториев и совместной разработки.
  5. GitHub Pages — сервис публикации статических веб-сайтов.

Работа с Git и GitHub

Git позволяет отслеживать изменения в исходном коде, создавать отдельные ветки разработки и объединять результаты работы.

Основные операции Git

  • Clone — создание локальной копии удалённого репозитория.
  • Commit — сохранение изменений в локальной истории проекта.
  • Branch — создание отдельной ветки разработки.
  • Merge — объединение изменений из разных веток.
  • Push — отправка локальных коммитов в удалённый репозиторий.
  • Pull — получение изменений из удалённого репозитория и их интеграция в текущую ветку.

Совместная разработка

GitHub позволяет организовать командную работу над проектом. Разработчики могут создавать копии репозиториев, предлагать изменения через Pull Request, просматривать код и обсуждать результаты работы.

Этапы разработки проекта

При подготовке демонстрационного проекта были выполнены следующие действия:

  1. Создана копия открытого репозитория (Fork).
  2. Репозиторий клонирован в Visual Studio Code.
  3. Изменён исходный HTML-код страницы.
  4. Созданы коммиты с описанием изменений.
  5. Созданы отдельные ветки разработки.
  6. Выполнено объединение веток (Merge).
  7. Создан и объединён Pull Request.
  8. Сайт опубликован через GitHub Pages.
